# Student Performance Data Analysis

This project analyzes student performance data using Python libraries such as Pandas and Matplotlib.

## Tasks Performed
- Data loading and preprocessing
- Checking missing values
- Removing duplicate records
- Calculating average final grades
- Finding students scoring above 15
- Correlation analysis between study time and performance
- Gender-wise performance analysis
- Data visualization using graphs

## Tools and Libraries Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Dataset
Student Performance Dataset from UCI Machine Learning Repository.
